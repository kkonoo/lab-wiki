기초와 구성 — 면역계는 무엇으로 이루어지나

면역계는 전체적으로 어떻게 짜여 있나?

Aliases: immune system · 선천면역 · 적응면역 · HSC · CMP · CLP · myeloid · lymphoid · leukocyte · PMN · MNC · NK · NKT · 조혈 · 계통도

골수 HSC → 골수계·림프계 두 갈래 → 혈액과 조직의 면역세포. 같은 지도를 계통(어디서 왔나)과 역할(선천·적응)로 다시 칠하면 두 분류가 어긋나는 세포가 드러남.

한 장 지도 — 조혈 계통도Who comes from where

배경 띠 = 장소(골수·흉선 → 혈액 → 조직) · 색 = 계통 또는 역할 · 세포에 마우스 → 계통·역할·경로 표시 · 아래 용어 칩 → 그 이름이 가리키는 범위만 강조.

역할로 바꾸면 색이 변하는 세포 = 계통 ≠ 역할

NK — 림프계 출신 · 항원특이 수용체 없음 → 선천면역 Janeway 2001 · 같은 성격의 ILC — T·B식 다양화 항원수용체 없는 림프구 Vivier 2018

NKT — NK의 하위가 아니라 semi-invariant αβ TCR을 가진 T세포 · CD1d 위 당지질 인식 · NK 표지(CD161·CD56) 공유 → 빠른 반응의 innate-like Heller 2018

선천 ↔ 적응 한눈에How the two arms connect

선천면역 → 즉시 1차 방어 + 적응면역 시동 · 적응면역 → 며칠 뒤 특이적 작동 + 선천면역 재강화 → 한 방향 단계보다 되먹임 회로. 2장(선천)과 3·4장(적응)의 연결 지도.

이름이 가리키는 범위

혈액·면역세포 상위 용어의 포함 관계 · “그림에서 보기” → 위 지도에서 범위 강조.

HSC → CMP (골수계 전구) + CLP (림프계 전구)

합이 아니라 분화 방향 · 고전 모델의 가장 이른 갈림 Akashi 2000 · 인간 지도 수정안 Doulatov 2010

Blood = plasma (~55%) + formed elements (RBC + WBC + platelet)

원심분리 시 적혈구 ~45% · 버피코트(WBC+혈소판) <1% OpenStax A&P 2e StatPearls 2026 · Plasma

Leukocyte = WBC = granulocyte (= PMN) + mononuclear cell (MNC)

granulocyte 별칭 = polymorphonuclear leukocyte Janeway 2001 · 단핵세포 = mononuclear (PBMC = peripheral blood mononuclear cell) Kleiveland 2015

PMN = neutrophil + eosinophil + basophil

mast cell → 혈중 전구 불명확, 조직에서 분화 Janeway 2001 · 넓은 뜻의 granulocyte에 mast cell을 묶는 문헌도 존재 Aristizábal 2013

PBMC = lymphocyte (T + B + NK) 70–90% + monocyte 10–20% + DC 1–2%

Kleiveland 2015 · NKT = TCR 가진 T세포 하위 → T 안에 포함, NK와 나란한 항목 아님 Heller 2018

Lymphoid progenitor → B · T (적응) + NK · ILC (선천)

lymphoid ≠ adaptive · NK = 항원특이 수용체 없는 선천면역 림프구 Janeway 2001 · ILC = 다양화된 항원수용체 없는 림프구 Vivier 2018

조혈 장소의 이동 — 인간 발생

성인 지도의 출발점(골수 HSC)도 처음부터 골수에 있던 것 아님 → 난황낭 → AGM → 태아 간 → 골수 순으로 조혈 장소 이동. AGM = aorta-gonad-mesonephros · dpc = days post conception, 수정 후 일수 · CS = Carnegie stage.

  1. CS 7–8 · 16–18.5 dpc

    Yolk sac 난황낭

    첫 조혈세포 — primitive erythroid · monocyte/macrophage

  2. CS 14 → CS 17 이상

    AGM 부위

    첫 HSC 검출 — 30–32 dpc부터 · 최소 39–42 dpc까지

  3. 7–8주부터

    Fetal liver 태아 간

    HSC의 뚜렷한 존재 — AGM보다 늦게 검출

  4. CS 23 · 56 dpc

    Bone marrow 골수

    골수 형성 = 배아기 끝 표지 · 골수 HSC 활성 시작 시점 미확정

  5. 출생 후

    골수 HSC

    모든 혈구 세포의 공통 출발점 → 위 지도
