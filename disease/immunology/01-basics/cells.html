기초와 구성 — 면역계는 무엇으로 이루어지나

면역세포의 종류와 상태는 어떻게 구분하나?

혈액 분획 → 분모 → single-cell cluster → 종류와 상태. 같은 림프구 비율도 무엇을 100으로 놓았는지에 따라 20–40% · 70–90% · 74.1%.

이름이 비슷해서 섞이는 짝

Plasma ≠ plasma cell — 혈장(액체) vs 형질세포(항체 분비 B세포 계열) Janeway 2001

Buffy coat ≠ PBMC — 원심분리만 한 WBC+혈소판 층(과립구 포함) vs 밀도구배로 PMN을 아래로 보낸 단핵세포 분획 Kleiveland 2015

분모 사다리 — 무엇을 100으로 놓았나Same cells, different denominators

아래로 갈수록 분리·선별 단계 추가 → 분모가 좁아짐. 파란 행 = 림프구 — 같은 세포 종류가 단계마다 다른 숫자.

CBC complete blood count · WBC white blood cell · PMN polymorphonuclear leukocyte · PBMC peripheral blood mononuclear cell · DC dendritic cell

같은 림프구, 세 개의 숫자

WBC 기준 20–40% → PBMC 기준 70–90% → PBMC3k barcode 기준 74.1%. 논문의 “비율” → 분모(전혈 · WBC · PBMC · QC 통과 barcode)부터 확인.

single-cell 논문의 기본 조합 = UMAP(색 = cluster 주석) + 주석별 세포 수·비율.

같은 cluster, 다른 이름

PPBP cluster → Scanpy 튜토리얼 “Megakaryocytes” · Seurat 튜토리얼 “Platelet” → 주석 이름 = 분석자의 해석 → 마커와 함께 읽기.

scRNA-seq 비율 = 분리·포획·QC를 거친 barcode의 조성 → 혈액 속 조성(STEP 3·4)과 구분.

종류 type

계통에 묶인 정체성

  • 마커·계통으로 정의 — 예: CD14+ vs FCGR3A+ monocyte (위 PBMC3k)
  • 전사체 기반 재분류 → 인간 혈액 DC·monocyte·progenitor 새 아형 + 분리·기능 검증 Villani 2017
상태 state

맥락에 따라 바뀌는 프로그램

  • 같은 계통 안의 항상성 · 활성 · 질환 관련 상태 구분
  • AD mouse model의 disease-associated microglia(DAM) — 질환 맥락의 식세포 프로그램 Keren-Shaul 2017

분류 결과를 읽는 기준

  1. 전사체 cluster ≠ 기능적으로 독립된 세포 종류 — 곧바로 동일시하지 않기
  2. 상태 해석 → 조직 · 발달 시기 · 자극 이력 함께
  3. 발달 궤적 추정 ≠ 실제 계통추적 · 전사체 분류 + 기능 검증 결합 Papalexi & Satija 2018
