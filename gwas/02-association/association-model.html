GWAS — Association model

유전형과 형질의 연관은 어떻게 검정하는가?

Association testing — 변이마다 따로 genotype과 형질의 통계적 연관을 검정하는 절차. 정량 형질이면 선형회귀, 이분형이면 로지스틱 회귀를 씀 Purcell 2007. Genome-wide significance — 변이 하나하나가 아니라 GWAS 한 번 전체의 거짓양성률을 묶기 위해 쓰는 임계값. 관례값은 5×10⁻⁸ Sham 2014

genotype을 숫자로 바꾸는 순간Dosage coding

GWAS가 하는 계산은 변이 하나에 회귀 한 번. genotype AA · AB · BB를 B allele 개수 0 · 1 · 2로 바꾸면 설명변수가 되고, 거기에 형질을 회귀해 기울기 β와 p값을 얻음 Purcell 2007. 이 숫자를 dosage라고 부름. imputed 변이는 0 · 1 · 2 대신 기대값(예: 1.37)이 들어가고 모형은 그대로임 Loh 2015 dosage가 만들어지는 과정 (그림) →

β가 뜻하는 것

정량 형질에서 β는 B allele 하나가 늘 때 형질이 움직이는 양. 형질을 표준화했으면 단위가 표준편차임. 이분형이면 로지스틱 회귀의 계수라서 exp(β)가 odds ratio가 됨 Purcell 2007. 두 경우 모두 변이 하나만 넣은 marginal 효과라서, 같은 locus에서 LD로 묶인 이웃 변이도 비슷한 β를 돌려줌. 어느 변이가 원인인지는 이 단계에서 가려지지 않음 Schaid 2018 fine-mapping (그림) →

검정 통계량은 셋 중 아무거나

Wald · score · likelihood ratio 세 검정은 표본이 크면 같은 값으로 수렴함. 대규모 GWAS가 score test를 즐겨 쓰는 이유는 귀무 모형을 한 번만 적합하면 변이마다 다시 적합할 필요가 없어서임 Zhou 2018. 이 선택이 이분형 극단 불균형에서 문제가 됨

additive 코딩을 기본으로 두는 이유Genetic models

dominant는 allele 하나만 있어도 효과가 다 나오는 모형(0 · 1 · 1), recessive는 둘 다 있어야 나오는 모형(0 · 0 · 1). GWAS는 대부분 additive 하나로 genome 전체를 훑음 Tam 2019

additive가 쓸 만한 이유와 치르는 값

additive 코딩은 참값이 dominant나 recessive여도 효과의 일부를 잡아냄. 위 그림의 시뮬레이션에서 참값이 dominant일 때 additive 적합의 p값은 3.2×10⁻⁷으로 맞는 모형(1.6×10⁻⁷)과 크게 다르지 않음.

참값이 recessive면 사정이 달라짐. 같은 표본에서 additive 적합은 β̂ 0.04 · p 8.5×10⁻²로 기준을 넘지 못하는데, recessive 코딩으로 적합하면 β̂ 0.23 · p 9.8×10⁻⁶임. BB인 사람이 MAF²만큼만 있어서 그렇습니다 — MAF 0.30이면 9%뿐이고 MAF 0.05면 0.25%로 줄어듦

그래서 additive 하나만 돌리면 recessive 변이를 놓칠 수 있음. 모형을 여러 개 돌리면 검정 수가 늘어 임계값이 더 엄해짐. 질환에 따라 recessive · dominant · parent-of-origin · X 연관 모형을 따로 돌리면 추가 변이가 잡힌다는 보고가 있음 Tam 2019

5×10⁻⁸은 어디서 왔나Genome-wide significance

임계값은 변이 하나의 성질이 아니라 GWAS 한 번 전체의 성질. "이 연구에서 거짓양성이 하나라도 나올 확률(FWER)을 5%로 묶자"는 약속을 변이 하나당 p 임계값으로 환산한 것임 Sham 2014

LD가 검정 수를 줄임

이웃한 변이는 LD로 묶여 함께 움직이므로 검정 425,904개가 독립 425,904개는 아님. 위 시뮬레이션에서 FWER를 0.05로 묶는 임계값은 1.9×10⁻⁷이었고, 이를 거꾸로 환산한 유효 검정 수가 261,223개임. SNP 수로 Bonferroni를 하면 1.2×10⁻⁷로 필요 이상 엄해지고, 블록 수로 하면 1.7×10⁻⁶로 느슨해짐.

고유값으로 유효 검정 수를 추정하는 식(Li & Ji 2005)을 같은 유전체에 쓰면 181,021개가 나와 직접 잰 값보다 작음. 추정식은 중앙 근처에 맞춰져 있고 임계값이 걸리는 자리는 분포의 꼬리라서 그렇습니다. 이 페이지는 꼬리에서 직접 잰 값을 씀

실제 유전체에서 나온 숫자들

관례값 5×10⁻⁸은 HapMap ENCODE 영역으로 무한 밀도 지도를 모사한 시뮬레이션에서 FWER를 0.05로 묶는 값으로 얻어졌음. 밀도를 더 올려 외삽하면 7.2×10⁻⁸이 나옴 Sham 2014.

임계값은 집단에 따라 달라짐. 같은 방식으로 European 표본을 모사하면 3.1×10⁻⁸이고, 유전적 다양성이 큰 African 집단에는 더 엄한 값이 필요함 Sham 2014. AMD 자료에서 case · control 라벨을 permutation해 직접 추정한 값은 1.5×10⁻⁸이었고 독립 변이 약 300만 개에 해당함 1000G 2015.

그래도 5×10⁻⁸이 관례로 굳은 것은 연구 사이 비교를 위해서임. 탐색 목적으로는 10⁻⁶ 같은 느슨한 기준을 suggestive로 따로 부름 Schaid 2018 significance 용어 카드 →

임계값을 낮춰도 표본은 조금만 늘면 됨Power

엄한 임계값이 검정력을 깎는 것은 맞지만, 깎인 만큼을 메우는 데 드는 표본은 생각보다 적음. 검정 수가 기하급수적으로 늘어도 같은 검정력을 지키려면 표본은 선형으로만 늘리면 됨 Purcell 2007

검정력이 모자라면 양성 결과도 흔들림

검정력 부족은 음성 결과만 흐리는 것이 아님. 유의하다고 선언한 결과의 타당성까지 떨어뜨림. 초기 연관 보고 166건 가운데 후속 연구에서 안정적으로 재현된 것은 6건이었음 Sham 2014.

발견 단계에서 얻은 효과 크기는 winner's curse로 과대추정되기 쉬움. 재현 연구의 검정력을 계산할 때는 보정한 효과 크기를 써야 함 Sham 2014 winner's curse가 MR에서 하는 일 (그림) →

공변량으로 안 되는 것: 친족Mixed model

집단 구조는 principal component를 공변량으로 넣어 상당 부분 걷어낼 수 있음 Purcell 2007. 그런데 같은 표본 안에 형제 · 사촌이 섞여 있으면 PC로는 잡히지 않음. 이 문제를 모형 안으로 들여오는 것이 mixed model임 Loh 2015 조상 보정과 PCA (그림) →

random effect가 하는 일

mixed model은 변이마다 추정하는 고정 효과 옆에 개인별 polygenic random effect를 하나 더 둠. 이 random effect의 공분산이 genomic relationship matrix라서 친족 관계와 미세한 집단 구조가 한 모형 안에서 같이 흡수됨 Yang 2011.

효과도 수치로 나타남. 친족 비율을 0에서 50%까지 올린 시뮬레이션에서 top PC만 공변량으로 넣은 회귀는 친족이 늘수록 통계량이 부풀었지만 REGENIE · BOLT-LMM · fastGWA는 모든 설정에서 type I error를 지켰음 Mbatchou 2021. 친족이 많은 실제 코호트에서도 같은 순서가 나옴 — 참가자 71%가 3촌 이내 친족을 가진 MCPS 33,500명 BMI GWAS에서 λGC가 PLINK 1.40 · REGENIE 1.34 · GMMAT 1.24였음 Tan 2026.

mixed model을 쓰면 PCA 보정을 따로 더 할 필요가 없음. PCA는 BOLT-LMM의 구성 요소가 아님 Loh 2015

case가 적을 때 무너지는 것Case–control imbalance

biobank에서 질환 하나를 case로 두면 case:control이 1:100보다 심하게 기울어지는 일이 흔함. UK Biobank의 PheCode 1,688개 가운데 1,431개(84.8%)가 1:100보다 불균형했음 Zhou 2018. 이때 score 통계량이 정규분포를 따른다는 점근 가정이 깨짐

왜 꼬리에서만 어긋나나

case가 적으면 score 통계량에 기여하는 사람이 몇 안 됨. 분포가 비대칭이고 띄엄띄엄해져 정규 근사가 중앙에서는 맞고 꼬리에서는 어긋남. genome-wide 임계값이 걸리는 자리가 바로 그 꼬리임 Zhou 2018.

위 시뮬레이션에서 p < 0.001인 변이 비율은 기대값이 0.0010인데, 보정 없는 score test는 1:1에서 0.0007, 1:999에서 0.0060이었음. saddlepoint 보정을 거치면 같은 조건에서 0.0007과 0.0013임.

λGC로는 이 문제가 잘 보이지 않음. 같은 1:999 시뮬레이션에서 λ는 score test 1.12 · saddlepoint 보정 1.09으로 거의 차이가 없었는데, 꼬리의 거짓양성률은 여섯 배 가까이 벌어졌음. λ가 중앙값 기반이라서 그렇습니다. 불균형 형질에서는 λ 대신 임계값 근처의 거짓양성률을 봐야 함

p값과 효과 크기에 쓰는 보정이 다름

saddlepoint 보정은 score 통계량의 분포를 다시 구하는 방법이라 p값을 바로잡음. 효과 크기는 귀무 모형 모수로 근사해 얻으므로 p값만큼 정밀하지 않음 Zhou 2018.

Firth 보정은 penalized likelihood로 계수 자체를 추정하는 방법이라 효과 크기까지 바로잡음. 낮은 minor allele count에서 saddlepoint 쪽 효과 크기가 크게 부풀 수 있다는 보고가 있어, p값은 saddlepoint · 효과 크기는 Firth로 나눠 쓰는 쪽이 안전함 Mbatchou 2021.

불균형이 무서워 rare 변이를 통째로 빼는 관행은 실제 연관을 놓치게 함. glaucoma와 유의하게 연관된 MYOC nonsense 변이의 MAF가 0.14%였음 Zhou 2018

결과 읽기의 흔한 오해Common misreadings

p < 5×10⁻⁸이면 그 변이가 원인 ✗

연관 검정은 변이 하나만 넣은 marginal 회귀라서 LD로 묶인 이웃이 함께 올라옴. 어느 변이가 원인인지는 fine-mapping과 기능 근거가 가림 Schaid 2018

5×10⁻⁸은 모든 GWAS에 맞는 값 ✗

임계값은 검정 수와 LD 구조에 달려 있음. 다양성이 큰 집단은 더 엄한 값이 필요하고, 변이 밀도를 올리면 값이 내려감 Sham 2014

additive 코딩이면 어떤 유전 모형이든 잡힘 ✗

참값이 recessive면 BB인 사람이 MAF²만큼뿐이라 검정력이 크게 떨어짐. 위 시뮬레이션에서 같은 표본의 p값이 9.8×10⁻⁶에서 8.5×10⁻²로 밀림 Tam 2019

mixed model을 쓰면 QC를 덜 해도 됨 ✗

mixed model이 구조와 친족을 흡수해도 genotyping 실패가 형질과 얽히면 거짓 연관이 남음. 결측률이 case와 control에서 다른 변이는 일반적인 Hardy–Weinberg 필터로 걸러지지 않음 Purcell 2007 · 세심한 QC는 여전히 필요함 Loh 2015

mixed model이 내놓는 h²를 SNP heritability로 읽어도 됨 ✗

BOLT-LMM의 h²_g에는 cryptic relatedness와 집단 구조의 기여가 섞여 있음 Loh 2015 · SAIGE가 추정하는 분산 성분 τ는 편향돼 있어 heritability로 쓰면 안 됨 Zhou 2018 heritability를 재는 법 (그림) →

공변량을 넣으면 검정력이 올라감 ✗

대체로는 올라가지만 예외가 있음. case-control 로지스틱 회귀에서는 알려진 공변량을 넣어도 검정력이 줄 수 있음 Sham 2014 무엇을 공변량으로 넣나 (그림) →

λGC가 1에 가까우면 아무 문제 없음 ✗

λ는 중앙값 기반이라 꼬리의 어긋남을 못 봄. 불균형 이분형에서는 λ가 멀쩡해도 임계값 근처에서 거짓양성이 늘 수 있음 Zhou 2018 QQ plot과 λGC (그림) →
