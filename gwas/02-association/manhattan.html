GWAS — Reading results

GWAS 결과는 어떻게 읽는가?

Manhattan plot — SNP마다 따로 계산한 연관 p-value를 genome 전체에 걸쳐 보여 주는 요약 그림 Schaid 2018. QQ plot — 관측 p-value를 크기 순으로 null 기대값과 비교하는 진단 그림 Sham 2014. Summary statistics — SNP별 per-allele 효과크기(case–control이면 log OR)와 표준오차, 분석에 따라 allele frequency까지 담은 결과 표 Pasaniuc 2016

Manhattan plot이 보여 주는 것Manhattan plot

가로축은 염색체 위치, 세로축은 −log₁₀ p. 수백만 SNP를 한 장에 요약하는 그림이고, 관심 region은 regional plot으로 이어서 봄 Pruim 2010. 아래 그림은 가상 형질 하나를 표본 크기만 바꿔 분석한 결과

요소읽는 법
가로축1번부터 22번 염색체를 위치 순서대로 이어 붙임. 색 교대는 염색체 구분용
세로축−log₁₀ p. 7.3이면 p = 5×10⁻⁸, 위로 갈수록 강한 연관
점선genome-wide 유의 기준 p < 5×10⁻⁸. 흔한 변이에서 독립 검정 약 100만 개를 가정하고 전체 거짓양성률을 5%로 묶은 Bonferroni 보정 Tam 2019 · 유래와 한계는 significance 카드
탑(peak)한 locus에서 LD로 묶인 SNP들이 함께 올라와 생김. 보이는 연관 신호 대부분이 LD 때문이고, causal 변이는 보통 직접 genotyping되지 않음 Tam 2019 · LD 페이지

Manhattan plot에 없는 것

효과의 방향과 크기, allele frequency, 표본 수, 코호트 간 이질성은 그림에 없음. 그림이 쓰는 것은 summary statistics의 P 열 하나(그림 4) · peak는 causal variant도 target gene도 정하지 않음. 연관 신호 대부분이 non-coding 영역에 있어 fine-mapping과 기능 분석이 뒤따름 Tam 2019

표본이 커지면 기준선을 넘는 locus가 늘어남

그림 1: 같은 형질에서 2만 명이면 11개, 10만 명이면 381개, 30만 명이면 1,137개 locus. causal SNP 4,234개는 세 모드에서 똑같음 · 실제 GWAS도 형질마다 발견 속도가 급히 빨라지는 표본 크기가 있고, BMI · height · WHRadjBMI는 1만–100만 명 구간에서 발견 locus 수가 아직 포화되지 않음 Tam 2019 · 엄격한 기준 때문에 효과가 작은 SNP는 기준선을 넘지 못하고, 그래서 GWAS 유의 SNP만으로는 SNP heritability를 다 설명하지 못함 Tam 2019

이 페이지의 시뮬레이션

개인 genotype을 만들지 않고 SNP별 z를 바로 뽑음. 표본이 크고 효과가 작으면 단순회귀의 z 벡터는 평균 √N·Rβ, 공분산 R(LD 행렬)인 다변량 정규분포로 근사됨 Pasaniuc 2016 · 가상 유전체는 염색체 길이만 실제(GRCh37)를 따르고, LD 블록마다 founder haplotype 12개의 계통수로 SNP를 만듦(LD 페이지와 같은 모형) · 블록 사이 LD = 0 · SNP 수 ÷ 평균 LD Score = 52,230 · 형질은 정량 형질, causal SNP 효과는 정규분포. genetic correlation · PRS 페이지도 같은 유전체를 씀

QQ plot은 무엇과 무엇을 비교하나Quantile–quantile plot

관측 −log₁₀ p를 크기 순으로 null 기대값에 대해 찍음. n개 검정에서 r번째로 작은 p의 null 기대값은 r/(n + 1) Sham 2014. 점이 대각선을 따르면 검정 통계량이 null 분포대로 보정된 상태. 한 숫자 요약은 λGC = χ² 중앙값 ÷ 0.456(자유도 1 χ²의 null 중앙값) Price 2006

모양가능한 원인
대각선을 따르다 꼬리만 위로일부 SNP의 진짜 연관. QQ plot은 FDR 방법과 같은 정보를 보여 줌 Sham 2014
처음부터 전체가 위로아주 이른 순위부터 벗어나면 층화의 강한 신호로 읽음 Sham 2014 · 그러나 polygenicity만으로도 같은 모양 Bulik-Sullivan 2015 · 그림 2의 두 모드가 같은 λGC 1.19
저빈도 변이에서만 위로case–control 불균형과 낮은 MAF에서 검정 자체의 보정 실패. 대장암(case : control = 1 : 84) MAF < 0.01 변이의 λ(p 0.001 분위)가 SAIGE-NoSPA 1.68 · BOLT-LMM 1.71, saddlepoint 보정한 SAIGE 0.99 Zhou 2018
대각선 아래보수적인 검정 또는 과보정. 예: genomic control 보정을 이미 거친 summary statistics Bulik-Sullivan 2015

λGC 하나로 원인을 정하지 않음

polygenic 형질은 confounding이 없어도 λGC가 1을 넘고 표본이 클수록 커짐 Yang 2011 Loh 2015 · 그림 2: 두 모드의 λGC는 같지만 평균 χ²는 1.78 대 1.19 · 층화 모드에도 유의 locus 4개(최대 −log₁₀p 23)가 생김. 모두 집단 간 빈도 차를 크게 둔 블록 · 실제 예: lactase persistence 형질에서 2번 염색체(LCT)에 유의 SNP 다발, 그 밖 염색체에서도 SNP 4개가 층화만으로 유의 Price 2006

λGC로 나누는 보정의 한계

한 숫자로 나누면 SNP마다 다른 집단 간 분화를 무시함. 분화가 큰 SNP는 덜 보정되고 분화가 없는 SNP는 과하게 보정됨 Price 2006 · 예: λ = 1.43인 유럽계 449명 자료에서 rs10511418의 χ² 45.11 → genomic control 31.55(116,204 SNP 보정 p 0.0023, 여전히 유의) → EIGENSTRAT 11.57(보정 p 1.00) Price 2006 · λ = 1.163 정도의 inflation도 경계선상 결과를 genome-wide 유의로 밀어 올릴 수 있음 Purcell 2007

QQ가 통째로 들리면 confounding인가Polygenicity vs confounding

causal 변이와 LD가 강한 SNP일수록 χ²가 올라감. 반면 층화나 cryptic relatedness가 만든 팽창은 LD와 상관이 없음. LD Score regression은 이 차이로 둘을 가름 Bulik-Sullivan 2015

식: E[χ²j] = 1 + N·a + N·h²·ℓj / M · N = 표본 수, M = SNP 수, a = confounding 기여, ℓj = Σk r²jk Bulik-Sullivan 2015

ℓj

LD Score

SNP j와 주변 SNP 사이 r²의 합. 그 SNP가 주변 변이를 얼마나 많이 tagging하는지 Bulik-Sullivan 2015

λGC로 나누는 보정은 표본이 클수록 보수적

polygenicity가 있으면 confounding이 없어도 λGC가 표본 수에 따라 커짐. 그래서 λGC로 나누는 보정은 불필요하게 보수적이고, 표본이 클수록 절편으로 보정하는 쪽의 검정력 이득이 커짐 Bulik-Sullivan 2015 · 실제 GWAS 20여 개에서 절편이 λGC보다 평균 0.11 작았고, 모든 연구에서 기울기가 0보다 유의하게 컸음 Bulik-Sullivan 2015 · 그림 3 오른쪽: polygenic 형질의 λGC는 100만 명에서 1.39, 층화만 있는 형질은 2.91

절편을 읽을 때 주의

절편이 위로 치우쳐도 그것만으로 confounding의 증거는 아님. 모형 가정이 어긋나 생긴 치우침이면 보정 인자가 보수적이 될 뿐 Bulik-Sullivan 2015 · FST와 LD Score가 무상관이라는 가정은 linked selection으로 깨질 수 있고, 층화 시뮬레이션에서도 기울기가 평균적으로 0보다 약간 컸음 Bulik-Sullivan 2015 · genomic control을 이미 거친 summary statistics는 절편이 1보다 작게 나옴 Bulik-Sullivan 2015 · specialty array(Immunochip 등) 자료는 LDSC에 맞지 않음 Pasaniuc 2016 · 아주 큰 표본에서는 강한 신호가 회귀를 흔들어 절편의 불확실성이 커짐(그림 3 오른쪽, 100만 명에서 0.91 ± 0.10)

LDSC는 QC를 대신하지 않음. genotype 수준에서 confounding을 직접 보정하는 것이 먼저이고, 절편 보정은 summary statistics만 있을 때의 사후 수단 Bulik-Sullivan 2015 · 층화 보정(PC · mixed model)은 covariate 카드 · 기울기로 heritability와 두 형질의 genetic correlation을 구하는 것은 genetic correlation 카드

summary statistics 한 줄에 담긴 것Summary statistics

핵심은 SNP별 per-allele 효과크기와 표준오차이고, 일부 분석은 allele frequency도 요구함 Pasaniuc 2016. z = 효과크기 ÷ 표준오차, null에서 표준정규분포 Pasaniuc 2016. 개인 genotype 없이 공유되는 형태라 대부분의 post-GWAS 분석이 여기서 출발함

두 연구를 합치기 전에: allele 정렬Harmonization

두 연구의 같은 SNP 효과는 같은 effect allele 기준이어야 비교 · 결합할 수 있음. effect allele을 모르면 맞출 방법이 없음. MR-Base는 allele과 필요하면 EAF로 자동 정렬함 Hemani 2018

경우예처리
effect allele이 반대A: G/T · B: T/GB의 효과 부호를 뒤집음 Hemani 2018
strand가 반대A: G/T · B: C/A한 연구가 forward, 다른 연구가 reverse strand로 보고한 경우. B의 allele를 상보 염기로 바꾼 뒤 정렬 Hemani 2018
palindromic(A/T · G/C)두 연구 모두 A/T, A의 빈도 0.11 대 0.91두 strand에서 글자가 같아 allele만으로는 구분 불가. 같은 조상 집단이면 EAF로 판단: 한쪽은 minor, 다른 쪽은 major → 다른 strand로 보고 한쪽 부호를 뒤집음. EAF가 0.5에 가까우면 판단 근거가 못 됨 Hemani 2018

정렬이 틀리면 생기는 일

BETA 부호가 SNP마다 제멋대로 뒤집혀 meta-analysis에서는 효과가 상쇄되고, MR에서는 도구변수 효과의 방향이 틀어짐. 그래서 MR 분석에서 palindromic SNP는 코딩 오류에 특히 취약한 것으로 다룸 Hemani 2018 · coloc에서도 두 형질의 β 방향이 같은 allele 기준이어야 함(coloc 페이지)

결과 읽기의 흔한 오해Common misreadings

Manhattan peak 꼭대기 SNP = causal variant ✗

peak는 LD로 묶인 SNP들이 함께 올라온 것이고 causal은 보통 직접 genotyping되지 않음 Tam 2019 · fine-mapping 페이지

λGC > 1 = 층화 ✗

polygenic 형질은 confounding 없이도 λGC가 1을 넘고 표본과 함께 커짐 Loh 2015 · 위 그림 3

QQ plot 모양으로 원인을 가름 ✗

λGC 1.32로 같은 두 시뮬레이션의 QQ plot이 사실상 같았는데 절편은 1.30(층화)과 1.006(polygenic) Bulik-Sullivan 2015

기준선 아래 = 효과 없음 ✗

엄격한 기준 때문에 효과가 작은 SNP는 넘지 못함 Tam 2019 · 그림 1에서 causal SNP 수는 세 모드가 같고 locus 수만 달라짐

p가 작을수록 생물학적으로 중요 ✗

연관 강도와 생물학적 가치는 비례하지 않음. statin 표적 locus의 GWAS 신호는 표현형 분산의 약 1%만 설명 Tam 2019

p = 귀무가설이 참일 확률 ✗

p는 귀무가설에 반하는 증거의 요약일 뿐, 데이터가 주어졌을 때 H0가 참일 확률이 아님 Sham 2014

λGC로 나누면 층화가 해결됨 ✗

분화가 큰 SNP는 덜 보정되어 가짜 신호가 남음 Price 2006 · polygenic 형질에서는 반대로 과보정 Bulik-Sullivan 2015

BETA 부호 = 위험 방향 ✗

부호는 effect allele 기준. 연구마다 effect allele이 다를 수 있어 정렬부터 함 Hemani 2018

GWAS 신호 대부분은 층화가 만든 것 ✗

일부 비판에 대한 반론: 층화 보정 방법, 생물학적으로 관련된 변이의 enrichment, family-based 검정에서의 재현, 여러 ethnic group에서 같은 SNP 확인 Tam 2019
