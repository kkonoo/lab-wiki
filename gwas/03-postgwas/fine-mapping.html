Post-GWAS — Signal resolution

GWAS 신호 안에서 causal variant는 어떻게 좁히나?

Fine-mapping — association이 나온 locus 안에 causal variant가 하나 이상 있다고 두고, variant마다 causal일 사후확률(PIP)을 계산해 후보를 좁히는 통계 분석. 결과는 PIP와, causal을 정해진 확률로 담는 최소 variant 집합(credible set) Schaid 2018

lead SNP ≠ causal variantWhy fine-map

GWAS에서 가장 작은 p-value를 낸 SNP(lead SNP)는 대개 causal이 아니라 causal과 LD로 묶인 대리표지 Schaid 2018. causal이 측정되거나 imputation되어 있어도 검정력이 부족하면 가장 작은 p-value가 아닐 수 있음 Schaid 2018. lead SNP가 causal일 확률은 효과 크기와 빈도에 따라 크게 다름. OR 1.5 · 빈도 50%인 변이는 약 79%, OR 1.1 · 빈도 5%인 변이는 2.4% Schaid 2018

그림에서 볼 것

causal은 p-value 순위 3위이고 lead SNP와 r² 0.88. PIP는 lead 0.60 · causal 0.08. lead SNP를 causal로 고르면 틀림. 대신 PIP를 큰 순서로 모은 95% credible set(SNP 3개)은 causal을 담고 있음.

이 예는 고른 것

같은 locus · 같은 causal · 같은 효과 크기(기대 z = 9)로 형질 표본만 바꿔 200번 반복한 결과: lead SNP = causal인 경우 90% · 95% credible set이 causal을 담은 경우 98% · credible set 크기 중앙값 2개(최대 5개). 위 그림은 lead와 causal이 갈린 경우를 골라 보여 줌. 효과가 이보다 작거나 LD가 강하면 갈리는 경우가 늘어남.

Bayes factor에서 PIP로Posterior inclusion probability

fine-mapping은 trait를 outcome, 주변 variant를 predictor로 둔 multiple regression에서 계수가 0이 아닌 variant를 고르는 variable selection 문제 Wang 2020. PIP는 variant의 계수가 0이 아닐 사후확률이고, 그 variant를 포함하는 모든 모형의 사후확률을 더한 값과 같음 Schaid 2018

STEP 1

SNP별 Bayes factor

β̂과 그 표집분산에 평균 0 · 분산 W인 정규 prior를 두면 Bayes factor가 닫힌 식으로 나옴 Sham 2014. "이 SNP 하나가 causal" 모형과 효과 없음 모형의 가능도 비

STEP 2

합이 1이 되게 나눔

causal이 정확히 하나라고 두면 PIPj = BFj / Σ BF(prior가 SNP마다 같을 때). z-score만으로 계산하므로 LD 행렬이 필요 없고 매우 빠름 Pasaniuc 2016

STEP 3

credible set

PIP를 큰 순서로 정렬하고 누적합이 ρ(보통 0.95)에 닿을 때까지 담음 Wang 2020 Schaid 2018

가정: region 안 causal은 하나, 그리고 데이터 안에 있음

이 계산은 causal marker가 region에 정확히 하나이고 그 marker가 데이터에 포함되어 있다는 가정에 기댐. 독립 신호를 먼저 나누는 분석의 예비 결과로 보라는 경고가 원 논문에 있음 Bycroft 2018. 신호가 둘 이상이면 아래 SuSiE, 패널에 없는 변이는 흔한 오해 참고.

credible set의 크기 = 남은 불확실성Credible sets

credible set = causal variant를 정해진 확률로 담는 가장 작은 SNP 집합. 보통 90% 또는 99% 수준 Pasaniuc 2016. SuSiE의 정의는 "effect variable을 적어도 하나 담을 확률이 ρ 이상인 집합" Wang 2020. causal과 LD가 강한 SNP가 많을수록 PIP가 여러 SNP에 나뉘어 집합이 넓어짐

넓은 credible set ≠ 실패

상관이 매우 높은 SNP들이 확률을 나눠 가지면 개별 PIP는 작아도, 그 집합 안에 effect variable이 있다는 결론은 강할 수 있음. 예: SNP 37개, purity 0.97인 credible set Wang 2020. credible set 안 PIP가 비슷하면 지금 표본으로는 구분할 수 없다고 읽고, 서로의 상관과 서로 보정한 효과 크기를 함께 봄 Schaid 2018

좁은 credible set은 드문 편. splice QTL 분석에서 credible set 2,652개 중 SNP 하나로 좁혀진 것은 457개 Wang 2020 · GTEx cis-eQTL 90% credible set 크기 중앙값 6개 GTEx 2020

신호가 둘 이상일 때: SuSiEMultiple causal variants

p-value 순위로 줄 세우는 방식은 causal이 하나일 때만 잘 맞음. causal이 여럿이면 가장 강한 SNP가 여러 causal을 동시에 tagging하고 있을 수 있음 Pasaniuc 2016. GTEx 규모의 eQTL에서는 locus마다 causal 하나라는 가정이 더는 맞지 않음 GTEx 2020

모형

효과 L개의 합

효과 벡터 b를 0 아닌 원소가 하나뿐인 벡터 L개의 합으로 씀. L = 1이면 single causal 모형과 같음 Wang 2020

적합

IBSS

나머지 L−1개 효과를 뺀 잔차에 single effect 회귀를 맞추는 일을 효과마다 돌아가며 반복. forward stagewise selection의 Bayesian 판이고, 변수 하나를 고르는 대신 변수에 대한 분포를 계산 Wang 2020

출력

효과마다 credible set

PIP = 1 − Π(1 − αlj) · 효과마다 credible set 하나 Wang 2020. credible set 수 = 신호 수, 크기 = 그 신호 안의 불확실성 Zou 2022

L은 상한

L을 실제 신호 수보다 크게 잡아도 결과는 대체로 안정. 남는 효과는 prior 분산이 0 근처로 추정되거나 purity 낮은 집합으로 걸러짐(시뮬레이션에서 실제 효과 1–5개에 L = 10) Wang 2020. LD를 바깥 패널에서 가져올 때는 예외. 아래 LD 행렬 참고.

독립 신호 개수를 먼저 세는 단계가 conditional/joint analysis(COJO). lead SNP로 조건화해 남는 신호를 찾음 Yang 2012. stepwise 선택은 SuSiE · FINEMAP과 경쟁하기보다 그 앞에 오는 단계

summary statistics와 LD 행렬로 할 때Summary-data fine-mapping

개인 genotype 없이 SNP별 z-score와 SNP 상관행렬(LD)만으로 likelihood를 계산할 수 있음 Benner 2016 Pasaniuc 2016. LD를 같은 표본에서 계산하면 SuSiE-RSS 결과는 개인 자료 SuSiE와 같고, 바깥 패널 LD를 쓸 때만 근사 Zou 2022. 성능 좋은 방법들 사이에서는 방법보다 어떤 LD 행렬을 쓰느냐가 결과를 더 크게 바꿈 Zou 2022

functional annotation을 prior로Functionally informed fine-mapping

annotation으로 SNP마다 causal prior를 다르게 줄 수 있음 Schaid 2018. 넣으면 power가 오르고 FDR이 내려감. 개선 폭은 annotation과 summary statistics를 함께 모델링하는 방법(CARMA · fastPAINTOR)이 두 단계로 나눈 방법(SuSiE + PolyFun)보다 큼 Yang 2023

prior 하나로 PIP가 뒤집힘

AD 데이터에서 SORL1 rs74685827의 PIP는 annotation 없이 0.009, PolyFun annotation을 넣으면 1.000 Yang 2023. 검정력이 약하거나 SNP 상관이 클수록 prior의 영향이 커지고, 잘못 정한 prior는 non-causal SNP에 큰 PIP를 줌 Schaid 2018. 결과와 함께 prior를 어떻게 넣었는지 기록.

여러 ancestry를 함께 쓰기

집단마다 causal과 LD로 묶인 tag SNP가 다르므로, 여러 집단의 증거를 합치면 tag SNP 신호는 흐려지고 causal 신호는 남음 Pasaniuc 2016. 가정은 causal SNP 집합이 모든 집단에서 같고 효과 크기 차이는 허용 Schaid 2018. 다인종 PAGE 표본에서 credible set이 유의하게 좁아짐(paired t-test P = 0.01) Wojcik 2019

결과 읽기의 흔한 오해Reading PIP and credible sets

lead SNP = causal ✗

LIPC locus에서 가장 작은 p-value의 rs2043085보다 r² 0.81로 묶인 rs7350789가 causal 근거가 더 컸음 Benner 2016 · 위 그림 1

PIP 높음 = causal 확정 ✗

효과가 0이 아닌 SNP를 편의상 causal이라 부를 뿐, 통계 방법만으로 인과는 확정되지 않음 Schaid 2018 · PIP 순위 = 주어진 모형과 입력 아래의 통계적 우선순위 Yang 2023 · 확정은 기능 실험

credible set 밖 = causal 아님 ✗

어떤 credible set에도 없다는 사실이 effect variable이 아니라는 뜻은 아님. 유의하지 않은 p-value가 귀무가설이 참이라는 뜻이 아닌 것과 같음 Wang 2020 Yang 2023

PIP만 보면 됨 ✗

PIP는 변수마다 따로 낸 요약이라 "1 또는 2 중 하나"라는 묶음을 담지 못함. 완전상관 쌍이 둘이면 네 SNP의 PIP가 모두 0.5 근처 Wang 2020 · credible set 단위로 읽기

95% credible set = 95% 보장 ✗

Bayesian 집합이라 frequentist coverage를 보장하지 않음. 시뮬레이션에서 대체로 0.90–0.95 Wang 2020 · 바깥 LD에서는 목표 미달 Zou 2022

SNP 하나짜리 credible set이 많을수록 좋음 ✗

바깥 LD가 어긋나면 상관된 SNP가 "주변과 약하게 상관된 큰 신호"처럼 보여 PIP ≈ 1인 단독 집합이 늘어남. 이런 집합의 coverage는 나쁨 Yang 2023 · 위 그림 4

lead와 상관 높은 SNP만 남기고 시작 ✗

상관이 높으면 어떤 SNP도 큰 PIP를 얻기 어려우므로 사전 필터링은 성급함. 상관이 낮은 SNP도 후보 Schaid 2018

패널에 없는 변이도 후보에 듦 ✗

fine-mapping은 데이터에 있는 변이 사이에서만 고름. ARMS2/HTRA1 locus에서는 예전 패널에 없던 structural variant가 새 패널에서 가장 강한 연관 변이로 올라옴(imputation R² 0.89) 1000G 2015
