Post-GWAS — Interpretation

두 association 신호가 겹치면, 같은 causal variant일까?

Colocalization(coloc) — 같은 locus의 두 association 신호(GWAS · eQTL 등)가 하나의 causal variant를 공유하는지 summary statistics만으로 평가하는 Bayesian 분석. lead SNP 하나가 아니라 구간 전체의 신호 모양을 비교 Giambartolomei 2014

겹친 peak ≠ 같은 변이Overlap is not sharing

GWAS hit 근처의 eQTL → “이 유전자가 원인” 추론의 출발점. 하지만 eQTL이 유전체·조직마다 흔해 우연한 겹침도 흔함 → 눈으로 겹침을 비교하는 것만으로는 부족 Giambartolomei 2014. LD로 묶인 서로 다른 두 causal variant도 같은 자리의 peak로 보임 — 아래 두 모드는 peak 위치가 거의 같음.

그림에서 볼 것 — 꼭대기의 색

공유 → trait 2 꼭대기 점 = trait 1 lead와 r²가 높은 빨간 점 · 별개 → trait 2 꼭대기 = trait 1 lead와 r² 0.2–0.6인 점 → 같은 블록 안에서 신호 모양이 어긋남. coloc = 이 어긋남을 SNP별 Bayes factor로 수치화.

다섯 가설 — 구간마다 하나씩H0–H4

한 구간(locus)에서 “어느 SNP이 어느 trait의 causal인가”의 모든 배치를 나열 → 다섯 가설로 묶음 → 가설마다 사후확률 PP0–PP4(합 = 1) Giambartolomei 2014 · 가설 prior ≈ SNP 하나의 prior × 배치 수 Wallace 2020

핵심 가정 — trait마다 구간 안 causal variant 최대 1개

이 가정 덕분에 LD 행렬 없이 SNP 하나씩의 summary statistics로 계산 가능 · 서로 다른 집단에서 측정한 두 trait도 비교 가능 Wallace 2020. 가정이 깨지면 → 아래 신호가 둘 이상일 때.

계산 — SNP별 Bayes factor를 가설별로 합산Approximate Bayes factors

MCMC 없이 닫힌 식으로 끝나는 계산 → 유전체 전체도 몇 분 Giambartolomei 2014

STEP 1

SNP별 ABF

β̂ · var(β̂) → Wakefield approximate Bayes factor(“이 SNP이 causal”의 근거) · 효과크기 prior sd W = 0.15(정량 형질) · 0.20(case-control) Giambartolomei 2014

STEP 2

가설별 합

H1 = Σ ABF₁ · H2 = Σ ABF₂ · H4 = Σ ABF₁ᵢ·ABF₂ᵢ(같은 SNP) · H3 = ΣABF₁·ΣABF₂ − H4(서로 다른 SNP 쌍) Giambartolomei 2014

STEP 3

prior 곱 → 정규화

각 합 × 가설 prior(위 그림 오른쪽 열) → 합이 1이 되게 나눔 → PP0–PP4 Giambartolomei 2014

입력 — 두 trait의 같은 구간 summary statistics

prior p₁ · p₂ · p₁₂와 구간 크기Priors scale with the region

SNP 하나의 prior — p₁(trait 1만 causal) · p₂(trait 2만) · p₁₂(둘 다) Wallace 2020. 가설 prior는 배치 수를 곱한 값 → H1·H2·H4는 n에 비례, H3는 n²에 비례 → 같은 p₁₂라도 구간을 넓히면 H3 쪽으로 기울어짐 Wallace 2020

SNP마다 다른 prior — variant-specific prior (coloc 6.0.0)

모든 SNP에 같은 p₁·p₂ 대신 SNP별 가중치(prior_weights1 · prior_weights2) · 가설 prior 총량은 그대로 유지 · 출처 6가지 중 eQTL–TSS 거리 밀도가 가장 나음 → GWAS–eQTL에서 쓰기를 권장 Pullin 2025

효과는 작음 — pQTL–eQTL 정답 비교에서 recall 최대 +0.04 · precision 최대 +0.03(0.8 기준) · 80% 넘는 locus에서 |ΔPP4| < 0.01. 같은 GWAS 신호가 NEK6·PSMB7 eQTL 둘 다와 colocalize → 거리 prior 적용 시 PSMB7 PP4 0.42 · NEK6 0.98 → NEK6 쪽 · 가중치는 한 trait에만, 근거 공개 Pullin 2025

민감도 분석 — p₁₂를 바꿔도 결론이 남는가Sensitivity analysis

p₁₂를 한 값으로 정하기 어려움 → 그럴듯한 범위를 훑어 결론이 유지되는지 확인 Wallace 2020. 데이터를 다시 돌릴 필요 없음 — 기존 사후확률 × (새 prior / 옛 prior) → 다시 정규화 Wallace 2020 · coloc sensitivity() coloc 문서

왜 흔들리나 — LD로 묶인 SNP이 많을 때

강한 LD로 묶인 SNP k개의 Bayes factor가 비슷 → 데이터가 “k개 중 같은 SNP(H4)”과 “k개 중 서로 다른 두 SNP(H3)”을 구분 못함 → 배치 수 k(k−1) 대 k → prior가 결론을 정함. 이 페이지 예: trait 1 lead와 r² ≥ 0.8인 SNP 90개 → PP4 0.91 → 0.50(p₁₂ 10⁻⁵ → 10⁻⁶).

실제 사례 — ANGPTL3 liver eQTL ↔ LDL: 강하게 연관된 변이 98개 · 신호 모양은 일치 → p₁₂를 10⁻⁵ 대신 10⁻⁶으로 쓰면 PP4 91% → 49% Giambartolomei 2014

신호가 둘 이상일 때Multiple causal variants

single causal 가정이 깨지면 → coloc은 사실상 두 trait의 가장 강한 신호끼리 비교 Wallace 2020 → 2차 신호의 공유를 놓침(예: trait 1의 두 번째 신호만 trait 2와 공유) Wallace 2020

결과 읽기 — 흔한 오해Reading PP0–PP4

PP4 높음 = 원인 유전자 확정 ✗

공유 변이의 근거일 뿐 — 상관이지 인과 아님 · 한 변이가 여러 유전자 발현을 바꾸면 구간의 여러 유전자가 모두 PP4 높게 나옴(예: SORT1 구간) Giambartolomei 2014 · 인과 확정은 CRISPR 등 실험 Wallace 2020

PP4 낮음 = 공유하지 않음 ✗

PP3도 낮고 PP0 · PP1 · PP2가 크면 → power 부족 Giambartolomei 2014 · 맞는 조직·상태를 측정하지 않았을 가능성 Wallace 2020 → PP0–PP4 다섯 값을 모두 보고

PP4 / (PP3 + PP4)만 보고 ✗

정의상 “두 trait 모두 연관”을 전제한 조건부 비율 → PP0–PP2에 몰린 locus도 높게 나올 수 있음 → 다섯 값과 함께

기본 prior 그대로 ✗

2018년 coloc 응용 논문 25편 중 22편이 기본값 사용 · p₁₂는 trait 쌍마다 달라야 함 → 선택 근거 + 민감도 분석을 결과와 함께 제시 Wallace 2020

구간은 넓을수록 안전 ✗

SNP 수 n ↑ → H3 prior ∝ n² → 같은 p₁₂로도 H3 쪽으로 기울어짐(위 prior 그림) Wallace 2020 · 옆의 독립 신호까지 들어오면 single causal 가정도 깨짐

causal 변이가 패널에 없어도 됨 ✗

causal 변이가 genotyping·imputation에서 빠지면 PP4 분산이 커지고 낮아지는 경향 · 줄어든 몫은 PP3보다 PP0–PP2로 → power 손실로 나타남 Giambartolomei 2014 · 두 dataset 공통 SNP만 쓰이므로 nsnps 확인 coloc 문서

PP4 > 0.8이 정해진 기준 ✗

고정 기준 없음 — 0.8이 널리 쓰임 Pullin 2025 · 원 논문은 75% Giambartolomei 2014 · 0.5 규칙 예 Wallace 2020 → 기준과 이유를 함께 기록
